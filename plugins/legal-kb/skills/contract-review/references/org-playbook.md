# 조직 기준 인터뷰 · 덧씌우기 규칙

> claude-for-legal `commercial-legal` 의 `cold-start-interview`(Apache License 2.0) 흐름을 참고해 한국 계약 실무로 줄였다.

`contract_review` 의 기준표는 **법이 정한 선**(강행규정·무효·금지행위 = 빨강)과 **흔한 협상 자리**(노랑)를 담는다.
조직 기준은 그 노랑 자리에서 "우리는 어디까지 받는가"를 정한다. 법이 정한 선은 바꾸지 않는다.

## 인터뷰 — 빠른 5문항

한 번에 하나씩 묻고, 모르거나 건너뛰면 기본 기준표를 쓴다고 적는다.

1. **주로 누구 편인가** — 계약 종류마다: 근로계약(사용자/근로자), 주택 임대차(임대인/임차인), 용역·하도급(발주·원사업자/수행·수급사업자).
2. **받아들이는 조건** — 숫자로 받는다.
   - 용역·하도급: 지체상금 일 요율·상한(예: 일 0.1%·계약금액 10%), 대금 지급기일(예: 수령 후 30일), 하자보수 기간, 손해배상 상한(계약금액 배수), 비밀유지 기간, 지식재산 귀속(발주자 귀속 허용 여부), 관할 법원
   - 주택 임대차: 원상복구 범위, 중도 해지 위약금, 수선 부담 경계, 특약 허용 범위
   - 근로: 수습 기간, 경업금지 기간·지역, 손해배상 예정 허용 여부(근로기준법 제20조로 빨강이라 바꿀 수 없음을 알린다)
3. **반드시 있어야 하는 조항** — 기준표의 빠진 조항 외에 조직이 넣는 것(예: 개인정보 처리 위탁 조항, 하도급 대금 직접 지급 조항).
4. **올리는 기준** — 어떤 판정이면 누구 승인이 필요한가(예: 빨강 하나라도 → 파트너, 손해배상 상한 없음 → 법무팀장).
5. **메모 형식** — 요약(결론·빨강·노랑만) / 상세(조항 전부·근거 원문). 기본은 요약.

## 저장 형식

사용자가 허락하면 `~/.claude/plugins/config/legal-kb/contract-playbook.md` 에 쓴다. 다음 검토부터 묻지 않고 읽는다.

```markdown
# 계약 검토 조직 기준
작성일: YYYY-MM-DD · 작성자: <역할>

## 용역·하도급 (service) — 관점: 수급사업자
- 받음(→green): 지체상금 일 0.1% 이하·상한 계약금액 10% 이하
- 받음(→green): 비밀유지 기간 3년 이하
- 거절(→yellow): 관할 법원이 상대방 본점 소재지 단독
- 필수 조항: 하도급대금 직접 지급

## 주택 임대차 (lease_house) — 관점: 임차인
- ...

## 근로 (labor) — 관점: 사용자
- ...

## 올림
- red 1건 이상 → 파트너 승인
## 메모
- 요약
```

## 덧씌우기 규칙

`contract_review` 결과를 받은 뒤 조항마다 적용한다.

| 도구 판정 | 조직 기준이 받음 | 조직 기준이 거절 | 기준에 없음 |
|---|---|---|---|
| green | green | **yellow** (`조직 기준: <항목>`) | green |
| yellow | **green** (`조직 기준: <항목>`) | yellow | yellow |
| red | **red 유지** — "위험 감수 결정 필요"로 올림 기준에 연결 | red | red |

- 조직 기준이 숫자로 정한 선(일 0.1% 등)은 계약서 숫자와 직접 비교한다. 비교할 숫자가 계약서에 없으면 바꾸지 않는다.
- 조직 기준이 법보다 불리한 쪽을 요구해도(예: 근로자에게 손해배상 예정) 빨강은 그대로 두고, 메모에 "조직 기준이 강행규정과 충돌"을 적는다.
- 필수 조항이 계약서에 없으면 빠진 조항 표에 `조직 기준` 표기로 노랑을 더한다.
- 바꾼 내역은 메모 "확인할 것" 절에 모두 적는다 — 검토자가 기본 기준표 판정과 조직 기준 판정을 구분할 수 있어야 한다.
